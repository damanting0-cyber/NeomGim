NeomGim 설치하기

NeomGim은 hitomi.la를 휴대폰에서 편하게 보게 해 주는 작은 프로그램이에요. 유저스크립트를 처음 들어 봐도 아래 순서대로 누르기만 하면 5분이면 끝나요.

안드로이드 휴대폰파이어폭스 앱인터넷 연결
아이폰 (iOS 15 이상)사파리Tampermonkey 앱 (유료)

먼저 알아 두기

유저스크립트는 특정 사이트에 들어갔을 때 그 화면을 바꿔 주는 작은 코드예요.

Tampermonkey는 그 유저스크립트를 설치하고 실행해 주는 브라우저 확장 기능이에요. 그래서 Tampermonkey를 먼저 깔고, 그다음 NeomGim을 깔아요.

크롬이나 삼성 인터넷은 이 방법으로 안 돼요. 안드로이드에서는 파이어폭스가 부가 기능을 제대로 지원해서 파이어폭스를 써요.

아이폰에서는 사파리 확장 기능으로 써요. 크롬 등 다른 앱은 확장 기능을 지원하지 않아요. Tampermonkey는 앱 스토어에서 한 번 결제하는 유료 앱이에요.

아이폰 버전은 아직 실제 아이폰에서 확인하지 못했어요. 안 되는 게 있으면 알려 주세요.

설치 순서

  1. 파이어폭스 설치

    Play 스토어에서 Firefox를 검색해서 설치하세요. 모질라(Mozilla)가 만든 주황색 여우 아이콘이에요.

    이미 있다면 Play 스토어에서 최신 버전으로 업데이트만 해 두세요.

  2. Tampermonkey 설치

    파이어폭스에서 아래 주소를 열고 Firefox에 추가를 누르세요.

    https://addons.mozilla.org/ko/firefox/addon/tampermonkey/

    권한을 묻는 창이 뜨면 추가를 누르세요. 비공개 탭에서도 쓸지 묻는 칸이 있으면, 비공개 탭에서도 볼 생각이면 체크하세요.

    주소가 안 열리면 파이어폭스 오른쪽 위(또는 아래) ⋮ 메뉴 → 부가 기능에서 Tampermonkey를 검색해도 돼요.

  3. NeomGim 설치

    파이어폭스에서 아래 주소를 여세요. Tampermonkey 설치 화면이 자동으로 뜨면 설치를 누르면 끝이에요.

    https://raw.githubusercontent.com/damanting0-cyber/NeomGim/main/NeomGim.user.js

    설치 화면 대신 코드가 글자로 쭉 보이면, Tampermonkey가 아직 안 깔렸거나 꺼져 있는 거예요. 2단계를 다시 확인하세요.

  4. hitomi.la 열기

    파이어폭스에서 hitomi.la에 들어가면 바로 바뀐 화면이 나와요. 오른쪽 아래에 검색 · 기록 · 설정 버튼과 H 버튼이 보이면 성공이에요.

  1. Tampermonkey 앱 설치

    앱 스토어에서 Tampermonkey를 검색해서 설치하세요. 유료 앱이에요. 설치한 뒤 한 번 열어 두세요.

    개발자 이름이 Jan Biniok인 앱이 맞아요. 이름이 비슷한 다른 앱도 있으니 확인하세요.

  2. 사파리에서 켜기

    아이폰 설정 → 앱 → Safari → 확장 프로그램 → Tampermonkey로 들어가서 켜세요.

    같은 화면의 웹사이트 권한에서 허용을 고르세요. 모든 사이트가 싫다면 나중에 hitomi.la에서만 허용해도 돼요.

    iOS 버전에 따라 설정 → Safari → 확장 프로그램으로 바로 보일 수도 있어요. 설치 화면이 새 탭으로 열리니, 잘 안 열리면 팝업 차단을 잠깐 꺼 두세요.

  3. NeomGim 설치

    사파리에서 아래 주소를 여세요. Tampermonkey 설치 화면이 뜨면 설치를 누르세요.

    https://raw.githubusercontent.com/damanting0-cyber/NeomGim/main/NeomGim.user.js

    코드만 글자로 보이면, 주소창 왼쪽의 가가(또는 퍼즐) 버튼 → Tampermonkey를 눌러 설치 화면을 여세요.

  4. hitomi.la 열기

    사파리에서 hitomi.la에 들어가세요. 사파리가 Tampermonkey에 이 사이트 접근을 허용할지 물으면 허용을 누르세요.

    오른쪽 아래에 검색 · 기록 · 설정 버튼과 H 버튼이 보이면 성공이에요.

처음 쓸 때 알면 좋은 것

작품 열기

목록에서 이미지를 누르면 작품이 커지면서 1페이지가 열려요. 제목을 누르면 태그와 작가가 나와요.

페이지 넘기기

화면 왼쪽 절반을 누르면 다음, 오른쪽 절반은 이전이에요. 옆으로 밀어도 넘어가요.

확대

두 손가락으로 벌리면 커져요. 위쪽 ↺ 버튼을 누르면 원래 크기로 돌아와요.

별점 · 일지

작품 화면 하단의 별을 누르고 별명을 정해 저장하면 일지에 남아요.

차단

목록에서 작품을 꾹 누르면 그 작품이나 작가를 숨길 수 있어요.

더 자세히

설정(톱니바퀴) 안의 ? 버튼에 기능 설명이 다 있어요.

업데이트

따로 할 일은 없어요. 새 버전이 나오면 Tampermonkey가 하루에 한 번쯤 확인해서 알아서 바꿔 줘요.

바로 받고 싶으면 NeomGim 설치 주소(3단계)를 다시 열고 업데이트를 누르세요. 저장해 둔 일지와 기록은 그대로 남아요.

안 될 때

hitomi.la에 들어가도 화면이 그대로예요

⋮ 메뉴 → 부가 기능 → Tampermonkey가 켜져 있는지 확인하세요.

Tampermonkey를 열어 NeomGim이 켜져 있는지(스위치가 초록색인지)도 확인하세요.

비공개 탭이라면 Tampermonkey 설정에서 비공개 브라우징에서 실행을 켜야 해요.

설치 주소를 열었는데 코드만 보여요

Tampermonkey가 설치되지 않았거나 꺼져 있어요. 2단계를 다시 하고 3단계 주소를 다시 여세요.

“유효하지 않은 유저스크립트”라고 떠요

주소를 잘못 열었거나 새 버전이 막 올라와서 반영 중일 때 생겨요. 3단계 주소를 그대로 복사해서 몇 분 뒤 다시 열어 보세요.

새로고침할 때 원래 사이트 화면이 잠깐 보여요

Tampermonkey 대시보드 → 설정 → 맨 위 설정 모드를 고급으로 바꾼 뒤, 주입 모드를 즉시로 바꾸면 줄어들어요.

잠깐 끄고 원래 사이트로 보고 싶어요

Tampermonkey 메뉴에서 NeomGim 끄기를 누르세요. 다시 켤 때는 같은 자리에서 NeomGim 켜기를 누르면 돼요.

지우고 싶어요

Tampermonkey를 열어 NeomGim 옆 휴지통 아이콘을 누르면 지워져요. Tampermonkey까지 지우려면 ⋮ 메뉴 → 부가 기능에서 제거하세요.

hitomi.la에 들어가도 화면이 그대로예요

주소창 왼쪽 가가(또는 퍼즐) 버튼 → 확장 프로그램 관리에서 Tampermonkey가 켜져 있는지 보세요.

같은 메뉴에서 Tampermonkey를 눌러 hitomi.la 접근을 항상 허용으로 바꾸세요.

Tampermonkey 앱에서 NeomGim이 켜져 있는지도 확인하세요.

설치 주소를 열었는데 코드만 보여요

주소창 왼쪽 가가 버튼 → Tampermonkey를 누르면 설치 화면이 열려요. 그래도 안 되면 2단계에서 사파리 확장이 켜져 있는지 확인하세요.

“유효하지 않은 유저스크립트”라고 떠요

새 버전이 막 올라와서 반영 중일 때 생겨요. 주소를 그대로 복사해서 몇 분 뒤 다시 열어 보세요.

개인 정보 보호 브라우징에서는 안 돼요

설정 → Safari → 확장 프로그램 → Tampermonkey에서 개인 정보 보호 브라우징에서 허용을 켜세요.

잠깐 끄고 원래 사이트로 보고 싶어요

주소창 왼쪽 가가 버튼 → Tampermonkey 메뉴에서 NeomGim 끄기를 누르세요. 다시 켤 때는 같은 자리에서 NeomGim 켜기를 누르면 돼요.

지우고 싶어요

Tampermonkey 앱에서 NeomGim 옆 휴지통 아이콘을 누르세요. Tampermonkey까지 지우려면 앱을 길게 눌러 삭제하면 돼요.

메뉴 이름은 브라우저 · iOS · Tampermonkey 버전에 따라 조금 다를 수 있어요.
